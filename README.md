# Geldi или gelmiş? — турецкое прошлое без зубрёжки

Mobile-first лендинг: разбор двух прошедших времён турецкого (-dı и -mış) в формате коротких историй, плюс продажа платформы Alterna A0 → C1 через lava.top.

**Интерактив:** крутилка «глаза / уши / сюрприз / сказка», переворачиваемые карточки, конструктор форм (10 глаголов × 6 лиц × 3 типа × 2 времени, формы генерируются по правилам гармонии), переключатель «мои глаза / мама, новости», квиз на 8 ситуаций, подбор под читателя, калькулятор времени на поиск материалов, видео-демо платформы.

**Техника:** чистые HTML/CSS/JS без сборки. Анимации на IntersectionObserver и CSS, с учётом `prefers-reduced-motion`. Шрифты: Bagel Fat One, Unbounded, Manrope.
